## 新增需求

### 需求：实时估值计算
系统 SHALL 基于估值记录、估值日期之后的成功交易记录和成功交付记录计算实时估值金额。

#### 场景：无额外交易的估值计算
- **给定** 估值记录金额 = 10000，估值日期 = 2024-01-01
- **且** 2024-01-01 之后无交易记录
- **且** 2024-01-01 之后无交付记录
- **当** 用户请求实时估值计算时
- **则** 系统返回 10000

#### 场景：含成功交易的估值计算
- **给定** 估值记录金额 = 10000，估值日期 = 2024-01-01
- **且** 2024-01-15 有一笔成功交易金额 = 2000
- **且** 2024-01-01 之后无交付记录
- **当** 用户请求实时估值计算时
- **则** 系统返回 12000

#### 场景：含成功交付的估值计算
- **给定** 估值记录金额 = 10000，估值日期 = 2024-01-01
- **且** 2024-01-01 之后无交易记录
- **且** 2024-02-01 有一笔成功现金交付金额 = 3000
- **当** 用户请求实时估值计算时
- **则** 系统返回 13000

#### 场景：含所有组件的估值计算
- **给定** 估值记录金额 = 10000，估值日期 = 2024-01-01
- **且** 2024-01-15 有一笔成功交易金额 = 2000
- **且** 2024-02-01 有一笔成功现金交付金额 = 3000
- **且** 2024-03-01 有一笔成功金融产品交付金额 = 4000
- **当** 用户请求实时估值计算时
- **则** 系统返回 19000

#### 场景：忽略失败交易
- **给定** 估值记录金额 = 10000，估值日期 = 2024-01-01
- **且** 2024-01-15 有一笔失败交易金额 = 5000
- **且** 2024-01-20 有一笔成功交易金额 = 2000
- **当** 用户请求实时估值计算时
- **则** 系统返回 12000（忽略失败交易）

#### 场景：忽略估值日期之前的交易
- **给定** 估值记录金额 = 10000，估值日期 = 2024-01-15
- **且** 2024-01-10 有一笔成功交易金额 = 5000（估值日期之前）
- **且** 2024-01-20 有一笔成功交易金额 = 2000（估值日期之后）
- **当** 用户请求实时估值计算时
- **则** 系统返回 12000（忽略估值日期之前的交易）

### 需求：估值计算 API
系统 SHALL 提供实时估值计算的 API 接口。

#### 场景：根据项目ID计算估值
- **当** 用户调用 GET /api/valuation/calculate/{projectId}
- **则** 系统返回计算后的估值金额

#### 场景：根据项目代码计算估值
- **当** 用户调用 GET /api/valuation/calculate?projectCode={code}
- **则** 系统返回计算后的估值金额

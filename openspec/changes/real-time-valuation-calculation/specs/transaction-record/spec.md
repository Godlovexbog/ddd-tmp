## 新增需求

### 需求：交易记录 CRUD
系统 SHALL 提供交易记录的完整增删改查功能。

#### 场景：创建交易记录
- **当** 用户提交包含所有必填字段的有效交易记录时
- **则** 系统创建记录并返回成功

#### 场景：根据ID查询交易记录
- **当** 用户根据已存在的ID查询交易记录时
- **则** 系统返回完整的交易记录

#### 场景：根据项目ID查询交易记录
- **当** 用户根据项目ID查询交易记录时
- **则** 系统返回该项目的所有交易记录

#### 场景：查询指定日期后的交易记录
- **当** 用户查询特定日期之后的交易记录时
- **则** 系统返回交易时间大于等于指定日期的所有交易记录

#### 场景：查询指定日期后的成功交易记录
- **当** 用户查询特定日期之后的成功交易记录时
- **则** 系统返回状态为SUCCESS且交易时间大于等于指定日期的所有交易记录

#### 场景：更新交易记录
- **当** 用户更新已存在的交易记录时
- **则** 系统更新记录并返回成功

#### 场景：删除交易记录
- **当** 用户删除已存在的交易记录时
- **则** 系统删除记录并返回成功

### 需求：交易记录字段
交易记录 SHALL 包含以下字段：
- targetId: Long - 标的ID
- targetCode: String - 标的代码
- targetSource: String - 标的来源
- transactionShare: BigDecimal - 交易份额
- transactionAmount: BigDecimal - 交易金额
- transactionStatus: Enum - 交易状态 (SUCCESS, FAILED, PENDING)
- transactionDate: LocalDateTime - 交易时间
